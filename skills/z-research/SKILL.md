# 外部事实研究

本 Skill 提供核对当前工作所依赖外部客观事实的方法，证据由 Agent 整合到整体任务。结论必须可追溯，研究深度由问题决定，不以来源数量或报告长度衡量完成；本方法不扩大项目写入、外部系统写入或后续实施授权。

## 研究问题

1. 把问题写成可验证主张，明确适用产品、版本、日期和决策用途。
2. 先检查环境中已有的官方文档连接器、项目锁定版本和本地缓存；不要向用户询问可自行取得的事实。
3. 优先官方文档、规范、源码、发行说明和许可证原文；社区内容只用于发现线索或补充实践。
4. 对会改变决定的主张逐项保留来源。一个权威来源足以回答时及时停止；来源冲突时核对版本、发布日期和适用条件。

简单事实给出短结论；跨多个主张、存在冲突或需要长期复用时形成正式报告。两种深度遵守同一来源质量标准，不强制后台 Agent、API Key、固定文件或来源配额。

正式报告默认在对话中交付；只有当前任务已有项目修改授权且后续工作确实长期依赖时才保存到项目事实来源。

## 输出

包含：

- 条件化结论；
- 每项关键主张的直接来源；
- 适用版本或核对日期；
- 冲突、未知和不能从证据推出的内容；
- 对原问题的影响及建议下一步。

网络或权限不足时说明已检查范围和缺失证据，不用记忆或惯例伪装为事实。问题解决后由 Agent 将结论整合到当前任务；只有后续工作长期依赖时才保存文档。
