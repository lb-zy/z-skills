# 神引

在首次写入或修改图谱前，把本 `SKILL.md` 所在目录解析为 `<skill-root>`，完整读取 [图谱规范](references/graph-spec.md)。按规范确定 `<spec>` 与 `<out>`；续作旧版本时先完成规范中的迁移门禁。

把 `<spec>` 作为唯一语义来源，把 `<out>` 作为可随时重建的派生视图。每个视图描述一个语义层；父图在当前层说明主题结构，子图只解释一个已确认非叶节点的内部机制。拓扑服从实际语义，关系、反馈和循环只在材料支持时出现。

## 紧回路

把一次用户回复中相互一致的决定组成一个**语义事务**；存在依赖冲突时按依赖顺序拆成多个事务。对每个语义事务执行同一个**紧回路**：

1. 原子应用事务中的全部决定，只更新 `<spec>`，再运行：

```sh
python3 <skill-root>/scripts/render_map.py \
  --spec <spec> \
  --out <out>
```

2. 校验失败时修正 JSON 并重跑。出现警告时让对应分支保持“待复核”；完成父子复核后使用 `--strict` 确认警告已清零。
3. 仅在输出包含 `"ok": true` 后展示更新后的 HTML，再进入下一个语义决定。

**完成条件：** 事务中的全部决定已写入 `<spec>`，输出包含 `"ok": true`，且最新 `<out>` 已展示。

## 启动或恢复

1. 新建图谱时，从用户明确表达的主题、问题、目标或材料中提炼中心语义。存在会改变中心含义的歧义时，每次只问一个影响最大的问题，直到中心语义唯一。
2. 继续既有图谱时，先读取并校验 `<spec>`；按规范迁移旧版本，保留可证明的确认项，再定位用户指定的视图或分支。
3. 在用户指定或当前任务授权的交付目录中确定 `<spec>` 与 `<out>`，只写入这一文件对。新建时先写入根视图的中心节点；继续时先从 `<spec>` 重新生成 `<out>`。
4. 把启动写入作为一个语义事务执行紧回路，使当前状态可见。

**完成条件：** 中心语义或续作分支唯一，交付路径确定，当前 JSON 通过校验，且对应视图已经可见。

## 构建当前层

1. 围绕当前中心提取表达本层所需的节点和关系。用户材料直接支持的事实与要求标为 `confirmed`；Agent 归纳出的结构标为 `candidate`，并把依据写入 `evidence`。
2. 先判断当前内容是流程、层级、真实循环还是自由网络，再按图谱规范选择布局。只表达材料支持的方向、依赖和反馈。
3. 把当前推导作为一个语义事务执行紧回路。中心节点明确后即可首次成图，候选结构随推导增量可视化。

**完成条件：** 当前视图包含解释本层所需的节点和关系；每一项均已分类；布局与实际结构一致；最新 HTML 完整、可读地展示当前层。

## 收敛当前层

1. 展示当前视图，请用户逐项或成批确认、修改、否决候选节点和关系。
2. 把一次用户回复作为一个语义事务：确认项转为 `confirmed`；否决项连同失效关系移除；修改项按新语义重建相关结构。执行紧回路后再请求下一批决定。
3. 当前视图不含候选项、关键语义一致且 HTML 可独立说明本层时，把 `status` 设为 `confirmed` 并再次执行紧回路。
4. 用户暂停时保留 `building`、未决候选项和最新文件，使下一次从同一语义状态恢复。

**完成条件：** 当前视图达到 `confirmed`；或用户明确暂停，且最新 `building` 状态已通过紧回路交付。

## 按需下钻

1. 只为用户选择的已确认非叶节点创建子视图。先定义父节点接口与版本，再按图谱规范建立父子双向引用并执行紧回路。
2. 在子视图重复“构建当前层”和“收敛当前层”。节点已成为可执行步骤、明确决策、可验证规则或具体事实，且继续拆分不再改善当前目标时，把它标为叶节点。
3. 父节点语义或接口改变时，按图谱规范触发“待复核”；完成接口与内部结构复核后再同步版本。
4. 选定分支已确认、达到叶节点或被用户暂停后停止，保留其他分支现状。

**完成条件：** 选定分支达到 `confirmed`、叶节点或已交付的 `building` 暂停状态。

## 验证与交付

1. 最终交付要求“待复核”清零时，在紧回路的渲染命令末尾追加 `--strict`。
2. 实际打开 HTML，在桌面宽度下验证文字完整显示、节点与连线间距清晰、布局符合内容结构、候选与确认状态同时由文字和线型区分，且键盘可聚焦节点；存在子图时，走通一次子图下钻、面包屑返回和顶层返回。
3. 验证页面只使用内嵌资源且运行无错误。浏览器检查不可用时，把对应项标为“未验证”并记录限制。
4. 交付自包含 HTML 与相邻 JSON。

**完成条件：** 所有可执行检查通过，未执行项有具体限制记录，且 HTML 与 JSON 已成对交付。
