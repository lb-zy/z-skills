## 12. 无障碍

默认目标为 [WCAG 2.2](https://www.w3.org/TR/WCAG22/) AA；对复杂控件参考 [ARIA APG](https://www.w3.org/WAI/ARIA/apg/)。如果项目采用其他等级或法定标准，在此写明。

| 主题 | 设计要求 | 验证 |
|---|---|---|
| 语义与名称 | 信息、控件、状态可由辅助技术理解 | 语义检查 + 读屏冒烟 |
| 键盘与焦点 | 全流程可操作，焦点可见、顺序正确、不意外困住 | 仅键盘任务测试 |
| 颜色与对比度 | 信息不只依赖颜色，文本和非文本对比度达到目标 | 自动扫描 + 人工检查 |
| 缩放与重排 | 放大、系统字号和窄屏下无内容丢失或遮挡 | 目标尺寸与缩放测试 |
| 运动与时限 | 支持减少运动；超时操作可延长、停止或恢复 | 系统偏好 + 定时流程测试 |
