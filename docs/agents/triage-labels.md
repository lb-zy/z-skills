# 分流标签

各 skill 使用五个规范化的分流角色。本文件将这些角色映射到本仓库问题跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此问题 |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 需求已完整说明，可以交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会处理此问题 |

当某个 skill 提到某个角色时，使用本表中对应的标签字符串。
